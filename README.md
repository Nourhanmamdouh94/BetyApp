# دفتر البيت

🔗 **التطبيق:** https://nourhanmamdouh94.github.io/BetyApp/

بلانر للبيت على الموبايل: شغل البيت، والطبخ والوصفات، وقوايم المشتريات، والمصاريف، في مكان واحد.

- **تطبيق ويب (PWA):** بيشتغل من المتصفح، وبيتضاف للشاشة الرئيسية على الآيفون، فيبان ويشتغل زي أي أبلكيشن.
- **من غير نت:** بعد أول فتحة، التطبيق بيشتغل حتى لو مفيش نت.
- **البيانات على موبايلك بس:** كل حاجة بتتحفظ على الموبايل نفسه (localStorage)، ومفيش سيرفر.
- **مصمم على مقاس iPhone 17** (402×874)، وبالعربي من اليمين للشمال.

---

## الملفات

| الملف | دوره |
|---|---|
| `index.html` | التطبيق كله: التصميم (CSS) والشاشات والمنطق (JS) |
| `manifest.webmanifest` | اسم التطبيق وأيقونته ولونه لما يتضاف للشاشة الرئيسية |
| `sw.js` | Service Worker: بيحفظ الملفات عشان التطبيق يفتح من غير نت |
| `icons/` | أيقونات التطبيق |
| `DESIGN-SYSTEM.md` | الـ Design System: الألوان، والـ Tokens، والمكونات، وهيكل التطبيق |
| `.nojekyll` | بيقول لـ GitHub Pages ينشر الملفات زي ما هي |

## ارفعيه على GitHub Pages (على حسابك الشخصي)

> اتأكدي إنك مسجلة دخول بحسابك **الشخصي**، مش حساب الشغل.

### ١) اعملي Repository
1. افتحي [github.com/new](https://github.com/new).
2. **Repository name:** مثلاً `daftar-elbeit`.
3. اختاري **Public**. ده شرط عشان GitHub Pages يبقى مجاني، وبياناتك مش هتبان لحد لأنها على موبايلك بس.
4. دوسي **Create repository**.

### ٢) ارفعي الملفات
1. في صفحة الـ repo دوسي **uploading an existing file**.
2. فكي ملف الـ zip، واسحبي **كل اللي جوه فولدر `daftar-elbeit`** (مش الفولدر نفسه) لصفحة الرفع.
   - اتأكدي إن فولدر `icons` اترفع بالصور اللي جواه.
   - ملف `.nojekyll` ممكن يبقى مخفي على الماك. اضغطي `Cmd + Shift + .` عشان يظهر.
3. دوسي **Commit changes**.

### ٣) شغّلي GitHub Pages
1. في الـ repo: **Settings ← Pages**.
2. **Source:** اختاري **Deploy from a branch**.
3. **Branch:** اختاري `main`، والفولدر `/ (root)`، ودوسي **Save**.
4. استني دقيقة أو اتنين، وهيظهر اللينك فوق:
   `https://nourhanmamdouh94.github.io/BetyApp/`

### ٤) ضيفيه للشاشة الرئيسية على الآيفون
1. افتحي اللينك من **Safari**. لازم Safari بالذات، مش Chrome.
2. دوسي زرار **المشاركة** (المربع اللي فيه سهم لفوق).
3. اختاري **Add to Home Screen**، وبعدين **Add**.
4. افتحي التطبيق دايماً من الأيقونة اللي على الشاشة الرئيسية. كده:
   - **بيفتح كامل** من غير شريط Safari.
   - **البيانات مش بتتمسح** حتى لو ما فتحتيهوش فترة.
   - **الإشعارات بتشتغل** (محتاجة iOS 16.4 أو أحدث).

## لما تعدّلي حاجة وترفعيها تاني
1. ارفعي `index.html` الجديد مكان القديم.
2. **غيّري رقم النسخة في `sw.js`**، مثلاً من `daftar-v8-7` لـ `daftar-v8-8`، وارفعيه هو كمان. من غير الخطوة دي، الموبايل ممكن يفضل يفتح النسخة القديمة.
3. اقفلي التطبيق على الموبايل وافتحيه تاني، أو اتنين لو التحديث ما ظهرش.

## احمي بياناتك
البيانات متخزنة على الموبايل بس:
- **نزّلي نسخة احتياطية كل فترة:** من **صورتك ← الإعدادات ← نزّلي نسخة احتياطية**، واحفظي الملف على iCloud أو أي مكان تاني.
- **لو غيرتي الموبايل أو مسحتي التطبيق:** هتحتاجي النسخة دي. من نفس المكان، دوسي **رجّعي نسخة احتياطية**.
